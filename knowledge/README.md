# Gatekeeper 基准库使用说明

> 基准库是搜索失败或数据时效不足（D1/D4 降级）时的**兜底依据**，不是首选数据源。
> 首选始终是实时搜索；基准库仅在无法获得时效合格数据时引用。

## 使用规则

1. **每个基准文件头部标注 `基准日期`**——引用时必须连同基准日期一起写入 `data_as_of`
2. **基准数据有效期 6 个月**：距当前日期超过 6 个月的基准文件视为过期，过期基准仅可作历史参照，必须标注 `[BASELINE_STALE]`
3. **引用基准库的判断同样受 G7 时效门禁约束**——基准日期即 data_as_of
4. 基准数据**禁止进入执行摘要和 TOP 风险的结论位**，除非实时搜索确认其仍然成立（此时以搜索来源为准，基准仅作交叉验证）
5. 每次推演如发现基准与现实严重偏离 → 在 `data_freshness.key_data_gaps` 中记录"基准库需更新：{文件名}"
