## 输入

| 输入项 | 说明 |
|--------|------|
| 发行 PE / 发行市值 / 募资 / 超募率 / 流通盘比例 | 发行文件口径；行业 PE 取同期中证行业静态市盈率 |
| 盈利状态 | 最近年报是否盈利 |
| 上市板块 | 科创板 / 港股 18C / 其他（v0.2 仅校准科创板，18C 参照使用并降置信） |
| **T0 时点 regime 快照** | 近 12 个月市场首日破发率 + 首日均涨（主锚）；近 3 个月首日均涨（辅锚） |
| 行业热度（v0.2 新增） | 标的所属行业近 90 日相对沪深 300 超额收益 |

## 规则

### R1【regime 判定】（证据 A，v0.1 沿用）
近 12 个月市场首日破发率 **<5% → 热 regime**；**≥5% → 非热 regime**。港股 18C 单独判定。
（首批盲测 3/3，含 regime 切换点压力测试通过）

### R2【P1 · 热 regime】（证据 A，v0.2 补四个缺口）
方向预测强制走**幅度带分支**：
- **基准幅度（V2）**：近 12 个月首日均涨为主锚；若近 3 个月均涨偏离主锚 >50%，取两锚均值（regime 过渡期）
- **幅度带边界（V1）**：预测值偏离基准 **±50% 以内 = 持平**；之外 = 显著高于 / 显著低于
- **个案调整**：
  - 流通盘 <10% → 上调一档
  - **题材热度（V3，客观化）**：行业近 90 日相对沪深 300 超额收益 >20% → 上调一档；<-20% → 下调一档（禁主观风口清单）
  - 发行市值 >500 亿 → 下调一档
- **带→点映射（V4）**：显著高于 = 基准 ×1.5 / 持平 = 基准 / 显著低于 = 基准 ×0.5

### R3【P1 · 非热 regime】（证据 A，v0.2 补零技巧结构）
破发概率 = 当期破发率基准 ± 个案调整（三分类：破发/平盘/上涨 + 点估计）。
- 冷 regime 基准：16%（2023-2024 组）；18C 基准：参照当期 18C 自身破发率
- **修正触发项（V5）**：
  - 发行 PE > 行业 PE **1.5x** → +10 点（v0.1 为 2x，首批盲测证明过窄：浩辰 1.2x 溢价破发未触发）
  - 超募率 >50% → +5 点
  - 题材热度（同 R2 客观标准）→ ∓10 点
- 三分类拆分：平盘 = 破发概率 ×0.75；上涨 = 1 − 破发 − 平盘（机械拆分，补 v0.1 缺口）

### R4【P2 · 热 regime】（证据 C，**检验中**，累计 2/3 案：1 胜 1 负）
6 个月回归概率（**V6 窗口判定**：上市日至 +6 个月**窗口内任一交易日**收盘 < 首日收盘 × 0.8）：
- 基准 **0.50**
- 反向指标修正：P1 带→点映射结果 >400% → +15 点；<150% → −10 点
- ⚠️ n=7 样本内观察 + 盲测 2 案（−0.44/+0.56），未定生死；下一案为协议要求的第三案
- 已知边界：热 regime 回归窗口可能为 6-9 个月（恒坤案：6m 时 1.06x → 8m 时 0.78x）；时点口径噪声大（先锋案贴线后修复）——V6 窗口判定即为应对此发现，其效果待批次 2 验证

### R5【P2 · 非热 regime】（证据 B，v0.2 补修正项）
6 个月"窗口内任一交易日收盘 < 发行价 × 0.8"概率：
- 基准 **0.40**（冷组 40%，注意测量时点污染——真实值可能更高）
- 修正触发项（V5）：未盈利 +10 点；发行 PE > 行业 1.5x +10 点；超募率 >50% +5 点

### R6【贱卖参照】（证据 A-，v0.1 沿用）
首日均衡价/发行价 ≈ regime 中位数：**热 3.74x / 冷 1.39x**。分布方差大，仅作谈判参照系。

## 禁区

1. 禁止用发行 PE / 超购倍数 / 中签率预测首日方向（证据 A：corr≈0，跨 regime）
2. 禁止跨市场平移 regime 数据（A 股 ↔ 港股分别锚定）
3. 禁止用历史破发潮（2022 前）统计外推当前
4. 点估计概率只允许出现在推断记录与预测区块（G5 C 型规则）
5. **禁止主观风口清单**——题材热度只许 V3 客观标准（v0.2 新增，首批盲测 3/3 执行体曾主观认定风口）
