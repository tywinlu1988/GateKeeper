## 规则

### R1【regime 判定】（证据 A，累计 6/6）
近 12 个月市场首日破发率 **<5% → 热**；**≥5% → 非热**。港股 18C 单独判定。
**V14 切换预警**：当近 3 个月与近 12 个月锚方向冲突（如 12 月非热但 3 月零破发）时，输出必须标注"regime 切换预警——置信下调"，但分支判定不变（上海合晶案验证：12 月窗口正确过滤切换初期噪音）。

### R2【P1 · 热 regime】（证据 A）
同 v0.2（基准幅度双锚规则 / 幅度带边界 ±50% / 个案调整三档 / V4 带→点映射 ×1.5/×1/×0.5）。
- **V3 题材热度（V11 缓冲带）**：行业 90 日超额收益（复利区间收益差，统一口径）>|25%| 确定触发；**∈ [15%,25%] 为边界带——强制双分支输出**（主分支不触发 + 敏感性分支触发，均入正式记录）；<|15%| 不触发
- V4 映射参数观察项：×1.5 累计 2/2 低估（先锋/电科），带均命中暂不调整

### R3【P1 · 非热 regime】（证据 B-，**V13 条件基准制——取代"总体基准+加点"**）
首日破发概率 = **发行 PE 分档条件基准**（冷组 n=73，F7）：

| 发行 PE | 条件基准 | n | 说明 |
|---------|---------|---|------|
| <30x | **0%** | 14 | 低价股被追逐，无一破发 |
| 30-60x | **22%** | 23 | |
| 60-100x | **27%** | 22 | 破发危险区 |
| >100x | **7%** | 14 | 题材溢价支撑（非单调，小样本谨慎） |

- 修正项（在条件基准上）：超募率 >50% → +5 点；V3 题材热度（含缓冲带双分支）→ ∓10 点；**禁止再对 PE 本身加点**（基准已分档，双重计算是 v0.2 日联案教训）
- 三分类拆分：平盘 = 破发 ×0.75；上涨 = 1 − 破发 − 平盘
- **V15 幅度公式**：首日涨幅点估计 = 当期 regime 首日均涨 ± V3 修正（热 ±20pp 超额 → ±10pp 幅度）

### R4【P2 · 热 regime】（证据 B，**V9 冻结反向指标修正项**）
6 个月窗口内任一交易日收盘 < 首日收盘 × 0.8 的概率 = **0.50（纯基准率，无修正项）**。
- 反向指标修正假设（首日 >400% → 上调）经三案盲测净效应 ≈0（-0.44/+0.56/0），**已检验-未证实，归档停用**
- 已知边界：热 regime 回归窗口可达 6-9 个月；本规则只答 6 个月窗口

### R5【P2 · 非热 regime】（证据 B-，**V13 条件基准 + V10 行业项**）
6 个月窗口内任一交易日收盘 < 发行价 × 0.8 的概率 = **发行 PE 分档条件基准**（冷组 F7，口径：最新价破发行率，含测量时点污染，真实值可能更高）：

| 发行 PE | 条件基准 | n |
|---------|---------|---|
| <30x | **21%** | 14 |
| 30-60x | **35%** | 23 |
| 60-100x | **55%** | 22 |
| >100x | **43%** | 14 |

- 修正项：未盈利 +10 点；超募率 >50% +5 点；**V10 行业热度：90 日超额收益 < −20%（含缓冲带双分支）→ +10 点**（上海合晶案：行业 -26.6% 崩塌此前无项可捕获）
- **禁止再对 PE 本身加点**（基准已分档）

### R6【贱卖参照】（证据 A-）
同 v0.1：热 3.74x / 冷 1.39x，仅谈判参照系。

## 禁区

1. 禁止用发行 PE / 超购倍数 / 中签率预测首日**方向**（证据 A：corr≈0）——PE 仅允许以"分档条件基准"形式进入概率修正
2. 禁止跨市场平移 regime 数据
3. 禁止用历史破发潮（2022 前）统计外推当前
4. 点估计概率只允许出现在推断记录与预测区块（G5 C 型规则）
5. 禁止主观风口清单；行业热度只许 V3/V11 标准（含统一复利口径与 V12 映射表）
