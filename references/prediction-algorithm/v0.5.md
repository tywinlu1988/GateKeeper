## 规则

### R1【regime 判定】（证据 A，累计 12/12）
近 12 个月**沪深 A 股**首日破发率 **<5% → 热**；**≥5% → 非热**。港股 18C 单独判定。V14 切换预警同前。

### R2【P1 · 热 regime】（证据 A，幅度带 4/4）
同 v0.4（双锚 / ±50% 边界 / V3-V11 题材缓冲带 / V4 映射）。

### R3【P1 · 非热 regime】（证据 B-，条件基准制累计六胜零负三平）
分档基准表同 v0.3（<30x 0% / 30-60x 22% / 60-100x 27% / >100x 7%）+ 超募（总额口径）/题材修正；PE 禁止单独加点。
- **V15′ 幅度公式（V17 修订，blind-batch-4 三案全灭教训）**：首日涨幅点估计锚 = **min(近 12 个月均涨, 近 3 个月均涨)** ± V3 修正——保守原则：幅度用于定价谈判参照，高估代价远大于低估；任何单一窗口在 regime 拐点都会失效（12 月滞后、3 月追高，N3）

### R4【P2 · 热 regime】（证据 B，基准查询规则）
6 个月窗口内任一交易日收盘 < 首日收盘 × 0.8 的概率 = **0.60**（F8，n=17 窗口口径）。
- 性质：基准查询（regime 复述），构造上零技巧；反向指标修正项维持冻结（V9）

### R5【P2 · 非热 regime】（证据 B-）
6 个月窗口内任一交易日收盘 < 发行价 × 0.8 的概率 = 分档基准（窗口口径）：

| 发行 PE | 基准 | 依据 |
|---------|------|------|
| <30x | **10%**（V18 自 21% 下调） | 窗口战绩 0/6（估算 0/5 + 益诺思案） |
| 30-60x | **35%**（下界） | F7 + 窗口案 1/1 |
| 60-100x | **55%**（下界） | F7 + 窗口案 2/2 |
| >100x | **43%**（下界） | F7 + 窗口案 2/2 |

- 修正项：未盈利 +10 / 超募（总额口径）>50% +5 / V10 行业热度 <-20% +10；PE 禁止单独加点
