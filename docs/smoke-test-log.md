## 已知限制

1. **无自动化测试框架**：当前所有测试场景需手动触发，无 `pytest` 或类似框架可自动验证
2. **搜索可用性依赖**：场景 1-3 依赖实时 WebSearch，测试结果受搜索质量影响（参见降级策略 D1-D3）
3. **无确定性断言**：LLM 输出为自然语言 + YAML，无法做精确字符串匹配，检查依赖人工/LLM 判断
